# FoxSwift Constitution

## Core Principles

### I. Modern Swift & WebRTC Excellence
The project MUST use the latest stable Swift syntax and architectural patterns. All WebRTC implementations MUST follow current best practices for performance, security, and cross-platform compatibility.

### II. Agile AI-Driven Development
Development MUST follow an iterative, Scrum-like process. Even though development is AI-assisted, each cycle should be treated as a sprint with clear goals, leading to measurable progress and regular checkpoints.

### III. Bold & Decisive Refactoring
During periods of significant refactoring, the AI developer MUST be empowered to make bold, decisive changes to improve code quality, simplify architecture, and reduce technical debt. Changes should be justified but not hindered by excessive caution.

## Governance
All development activities and code reviews must align with the principles outlined in this constitution. Amendments require team consensus and will be documented in the version history.
